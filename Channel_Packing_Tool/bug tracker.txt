=========Notes=========

=Version format:

e.g. 1.0.2

    first digit:
        Release. 0=unreleased. 1=released
    second digit:
        Feature version. goes up when features are added
    third digit:
        Bug fix. Goes up when bug is fixed


=PyInstaller:

    When using PyInstaller, open the Channel_Packing_Tool folder in terminal and use the following command:
        python -m PyInstaller main.py --onefile --icon=icon.ico --noconsole
    Remember to move Channel_Packing_Tool folder to same location as .exe file
